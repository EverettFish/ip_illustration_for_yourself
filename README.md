# 🐟 ip_illustration_for_yourself

> **A mini pen-doodle IP illustration skill for character building and article illustrations.**
>
> 把你自己，变成文章里的小主角。

用你的照片、个人形象、宠物、动漫角色或者任何你喜欢的形象，生成一套专属于你的 **萌粒风格 mini IP 小插画**，然后让它真正参与文章表达，而不是只做装饰。


---

## ✨ 这个 Skill 是做什么的？

`ip_illustration_for_yourself` 是一个专门用来制作 **个人 IP 文章配图** 的小插画 Skill。

它最核心的使用方式是：

1. 上传你的照片或人物参考图；
2. 建立一个稳定、可复用的 **萌粒风格 Q 版形象**；
3. 把一篇长文交给 Skill；
4. 它自动理解文章内容；
5. 用你的 IP 角色生成一组 **和文章意思强相关的配图**。

最终得到的不是普通的「可爱插画」，而是一套带有你个人辨识度的内容视觉系统。

---

## 🫧 什么是「萌粒风格」？

萌粒 = **萌** + **粒**。

- **萌**：Q 版比例、豆豆眼、圆头圆脑、松弛可爱；
- **粒**：角色在画面里很小很小，像一粒小豆子被丢在一张大白纸上。

它不是精致商业插画，也不是 AI 常见的那种「过度完美感」，而是刻意保留一种 **稚拙、mini、松弛、手绘感**。

核心视觉特点：

- **人物很 mini**，占画面比例很小
- **大量白色留白**，不怕空
- **Q 版比例**，头大身小
- **豆豆眼 / 简单五官**
- **钢笔一样的黑色描边**
- **线条自然抖动**
- **轮廓有明显但不机械的断断续续**，主要形体仍然清楚可读
- **转角不完全精准**，保留轻微犹豫、停顿和不均匀笔压
- **色块内部简单、干净**，边缘与描线允许少量露白或轻微溢出
- **颜色保持正常、清晰的饱和度**，不褪色、不做旧、不统一蒙灰
- **可爱来源于「不那么完美」**

> 理想效果像是：
> **一只很小的可爱角色，被人用钢笔随手画在一张大白纸上。**

## 🎁 它现在可以产出

这是这个 Skill 和普通「AI 画图」最不一样的地方：它不止画角色，还会把角色 **用起来**。

| 产出 | 长什么样 | 用在哪 |
|---|---|---|
| 🧍 **IP 形象图** | 你的专属萌粒角色，正面 / 侧面 / 常用动作 / 常用表情 | 头像、账号视觉、后续所有配图的锚点 |
| 🖼️ **Mini 文章插图** | 角色在具体场景里做一件具体的事，横向或方形，留白多 | 公众号、小红书、博客的段落配图 |
| 📊 **3:4 信息图** | 竖版长图，角色 + 结构化信息，观点、步骤、对比、清单 | 小红书封面、朋友圈九宫格、知识卡片 |

**Mini 插图** 负责讲情绪和场景，**3:4 信息图** 负责讲结构和干货。一篇文章通常两种都需要。

## 📐 3:4 信息图是怎么工作的？

很多人做知识卡片会翻车，因为把它做成了「PPT 截图 + 一个卡通人」。

这个 Skill 的做法不一样：**先有信息结构，再让角色进去演**。

它会自动做三件事：

1. **提炼结构**：从文章里抽出可以被卡片化的内容，比如 3 个步骤、4 个误区、2 组对比、1 张清单；
2. **排版**：标题 → 主体 → 小结，竖版 3:4，留白依旧很多，字不会挤满；
3. **让角色入场**：角色不是贴在角落的装饰，而是在示范、在指、在扛、在犯错、在恍然大悟。

支持的常见信息图类型：

- 📋 清单型（「写文章前必须确认的 5 件事」）
- 🪜 步骤型（「从 0 到 1 的四步」）
- ⚖️ 对比型（「新手 vs 老手」）
- ❌ 误区型（「三个千万别做的事」）
- 🧠 观点型（一句核心结论 + 一个小场景）
- 🗺️ 结构型（把一个方法论画成图）

> 默认情况下，mini 插图 **不加文字**，3:4 信息图 **才加文字**。
> 这样一篇文章里，图片有节奏，不会全是字。

## 🖊️ 为什么线条故意不那么顺？

这是这个 Skill 很重要的一部分。

我们并不希望它变成：

- 光滑矢量插画
- 商业卡通海报
- 精致动漫立绘
- 油画棒 / 蜡笔厚涂
- AI 常见的「过度精致感」

而是希望描边保留：

- 轻微抖动
- 不均匀粗细
- 小停顿
- 小缺口
- 偶尔断开的轮廓
- 有点笨拙的曲线

但与此同时，**色块不会故意搞得很脏**。

粗糙感主要来自 **钢笔轮廓线**，不是来自大面积斑驳笔刷。

## 🧠 它不会机械地「按段落配图」

文章配图最重要的不是「画够 5 张」，而是：

> **每张图到底有没有在表达文章里的东西？**

Skill 会先理解文章，再选择最值得视觉化的内容。

例如一篇文章里可能有：

1. 一个核心观点；
2. 一个具体经历；
3. 一个转折时刻；
4. 一个结构或方法；
5. 一个最终判断。

它会优先把这些真正有意义的节点画出来，而不是随机生成：

> 机器人 + 电脑 + 灯泡 + 星星 ✨

这种和任何 AI 文章都能通用的「废配图」。

判断规则也很简单：**如果这张图换到另一篇文章里也毫无违和，那它大概率就是废图。**

## 🧩 典型工作流

### STEP 01｜建立你的角色

上传 1～3 张参考图。

Skill 会提取：

- 发型 / 毛发
- 脸型
- 帽子 / 眼镜
- 衣服
- 主色
- 配饰
- 标志性特征
- 性格感觉

之后形成稳定的角色锚点，后面所有图都从这个锚点长出来。

> 💡 小技巧：一张正脸 + 一张全身 + 一张日常穿搭，出来的角色最稳。

---

### STEP 02｜把文章交给它

你可以直接粘贴完整文章，例如：

> 帮我用这个角色给这篇文章生成 5 张配图。
> 不要文字，保持 mini、留白多、钢笔粗糙描边。

或者：

> 这篇文章帮我做 1 张 3:4 封面 + 4 张 mini 插图，
> 封面要能一眼看懂核心观点。

Skill 会先理解内容，再设计每一张图的场景。

---

### STEP 03｜生成文章配图

默认推荐 **5 张**，当然也可以指定：

- 3 张
- 5 张
- 8 张
- 每个章节 1 张
- 只画封面
- 只画某一段
- 只要 3:4 信息图，做成九宫格

默认情况下，mini 插图里 **不会主动加入文字**。

---

### STEP 04｜微调和续画

角色定下来之后，你可以随时说：

> 第 3 张再夸张一点，人再小一点，留白再多一点。

或者一个月后回来继续用同一个角色写新文章。**角色是可以长期复用的，这才是「IP」的意义。**

---

## 🖼️ 还可以继续补参考图

只有角色图还不够？

完全可以继续加。

例如文章里提到了某个产品，你可以直接补：

- 品牌 Logo
- 产品照片
- 手机 / 电脑 / 机器人
- App 截图
- 网站 UI
- 包装
- 建筑
- 地点照片
- 课程页
- 海报
- 特定服装
- 特定道具

然后告诉 Skill：

> 保持我的角色和原来的画风，但这个产品请参考我新上传的图片。

这样既能保持统一的个人 IP，又能让文章里的具体事物更准确。

## 🌟 一个简单例子

假设你写了一篇：

**《第一次带孩子去看机器人展》**

配图不应该只是 5 张机器人。

更好的方式可能是：

1. 你的 IP 拿着票准备出发；
2. 你的 IP 第一次看到机器狗；
3. 机器人突然摔倒，你一脸震惊；
4. 孩子追着送餐机器人跑；
5. 回家后，你重新思考「机器人离生活还有多远」。

再配一张 3:4 收尾：**「带娃看机器人展的 4 个真实感受」**，角色站在四条信息旁边，指一指，歪个头。

这样图片本身就在帮助文章讲故事。

## 🙋 常见问题

**Q：每次生成的角色会不会不一样？**
A：第一步的角色锚点就是为了解决这个。锚点越具体（发型、颜色、标志性配饰），一致性越高。建议把第一次生成的角色图保存下来，之后每次带上。

**Q：可以出中文字吗？**
A：3:4 信息图默认带字。mini 插图默认不带字，需要的话直接说就行。图上文字量建议克制，字越少越好看。

**Q：可以画多个角色同框吗？**
A：可以，比如你 + 你的猫、你 + 同事。同框时角色会更小，留白依然保留。

**Q：可以商用吗？**
A：角色是你自己的，产出的图你自己判断使用范围。涉及真实品牌、真实产品、真人肖像时，请自己确认授权情况。

## ⚠️ 它不太适合什么

诚实一点比较好：

- ❌ 需要精致封面大图、厚涂质感的场景
- ❌ 需要严格品牌规范、矢量可缩放的 VI 物料
- ❌ 需要写实产品渲染图
- ❌ 一次要出几十张、且要求完全零偏差的批量生产

它擅长的是「小、松弛、有人味儿」，不是「大、精、准」。

---

## ❤️ 最终目标

`ip_illustration_for_yourself` 想做的，不只是「帮你生成几张可爱图片」。

它更希望变成：

> **属于你自己的文章视觉语言。**

当别人刷到一张小小的、稚拙的、钢笔描边略微断续的角色插画时，还没看到作者名字，就已经知道：

**「哦，这是你的文章。」**

这才是这个 Skill 最有意思的地方。
